## 🇭🇺 Magyar

Az Omni AI Workspace egy böngészőben futó, kliens oldali központi vezérlőpult (Dashboard), amely egységes felületen biztosít gyorselérést a legfontosabb mesterséges intelligencia modellekhez (szöveg, kép, videó, hang, kód), valamint egy beépített **AI Ügynök Gyárat (Agent Builder)** is tartalmaz[cite: 1].

###  Főbb Funkciók
* **Központi Eszköztár:** Gyorselérés a legnagyobb AI modellekhez (ChatGPT, Claude, Perplexity, Midjourney, Runway, Suno AI, ElevenLabs, Cursor, stb.)[cite: 1].
* **Intelligens Szűrés:** Kategóriák szerinti szűrés (Szöveg, Kép, Videó, Audio, Kód, Saját Ügynökök)[cite: 1].
* **Prompt Cheat Sheet:** Gyorsan beszúrható paraméterek, stílusok és formázások (pl. Midjourney képarányok, Markdown formázás)[cite: 1].
* **AI Ügynök Gyár (Agent Builder):** Saját, fix viselkedésű (System Prompttal ellátott) ügynökök létrehozása, mentése és sablonokból való legózása[cite: 1].
* **Adatvédelem:** Minden beállítás és mentett ügynök a böngésződ helyi tárhelyén (`localStorage`) tárolódik, nincs szükség szerverre[cite: 1].

### 🛠️ Használat
1. Nyisd meg az `index.html` fájlt bármelyik modern webböngészőben[cite: 1].
2. Válaszd ki a megfelelő fület (Eszközök vagy Ügynök Gyár)[cite: 1].
3. Írd be a feladatot, kattints az indítóra, mire a rendszer a vágólapra másolja a szöveget és megnyitja a céleszközt (`Ctrl + V`)[cite: 1].

## 🇬🇧 English

Omni AI Workspace is a browser-based, client-side central dashboard that provides unified, quick access to top AI models (text, image, video, audio, code) and includes a built-in **AI Agent Builder**.

###  Key Features
* **Central Toolset:** Quick access to major AI models (ChatGPT, Claude, Perplexity, Midjourney, Runway, Suno AI, ElevenLabs, Cursor, etc.).
* **Smart Filtering:** Filter by categories (Text, Image, Video, Audio, Code, My Agents).
* **Prompt Cheat Sheet:** Instantly insertable parameters, styles, and formatting options (e.g., Midjourney aspect ratios, Markdown formatting).
* **AI Agent Builder:** Create, save, and template your own fixed-behavior agents equipped with System Prompts.
* **Privacy:** All settings and saved agents are stored locally in your browser (`localStorage`), with no external server required.

### 🛠️ Usage
1. Open the `index.html` file in any modern web browser.
2. Select the desired tab (Tools or Agent Builder).
3. Type your task, click the launcher button, and the system will copy the text to your clipboard and open the target tool (`Ctrl + V`).

## 🇩🇪 Deutsch

Omni AI Workspace ist ein browserbasiertes, clientseitiges zentrales Dashboard, das einen einheitlichen und schnellen Zugriff auf die wichtigsten KI-Modelle (Text, Bild, Video, Audio, Code) bietet und einen integrierten **AI Agent Builder** enthält.

###  Hauptfunktionen
* **Zentrales Toolkit:** Schnellzugriff auf führende KI-Modelle (ChatGPT, Claude, Perplexity, Midjourney, Runway, Suno AI, ElevenLabs, Cursor usw.).
* **Intelligente Filterung:** Filtern nach Kategorien (Text, Bild, Video, Audio, Code, Meine Agenten).
* **Prompt Cheat Sheet:** Sofort einfügbare Parameter, Stile und Formatierungen (z. B. Midjourney-Seitenverhältnisse, Markdown-Formatierung).
* **AI Agent Builder:** Erstellen, Speichern und Vorlagenbasiertes Erstellen eigener Agenten mit festem Verhalten (System Prompts).
* **Datenschutz:** Alle Einstellungen und gespeicherten Agenten werden lokal im Browser (`localStorage`) gespeichert, kein externer Server erforderlich.

### 🛠️ Verwendung
1. Öffnen Sie die Datei `index.html` in einem modernen Webbrowser.
2. Wählen Sie das gewünschte Tab (Tools oder Agent Builder).
3. Geben Sie Ihre Aufgabe ein, klicken Sie auf den Startbutton, und das System kopiert den Text in die Zwischenablage und öffnet das Zieltool (`Ctrl + V`).
