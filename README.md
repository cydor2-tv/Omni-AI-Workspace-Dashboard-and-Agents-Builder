## 🇭🇺 Magyar

Az Omni AI Workspace egy böngészőben futó, kliens oldali (lokális vagy GitHub Pages-kompatibilis) központi vezérlőpult, amely egységes felületen biztosít gyorselérést a legfontosabb mesterséges intelligencia modellekhez, valamint egy beépített **AI Ügynök Gyárat (Agent Builder)** is tartalmaz[cite: 1]. A felület teljes mértékben **mobilra is optimalizált**, így okostelefonról vagy tábltegről is kényelmesen használható.

### 🚀 Főbb Funkciók
* **Központi Eszköztár:** Gyorselérés a legnagyobb AI modellekhez (ChatGPT, Claude, Perplexity, Midjourney, Runway, Suno AI, ElevenLabs, Cursor, stb.)[cite: 1].
* **Intelligens Szűrés:** Kategóriák szerinti szűrés (Szöveg, Kép, Videó, Audio, Kód, Saját Ügynökök)[cite: 1].
* **Prompt Cheat Sheet:** Gyorsan beszúrható paraméterek, stílusok és formázások[cite: 1].
* **AI Ügynök Gyár (Agent Builder):** Saját, fix viselkedésű ügynökök létrehozása, mentése és sablonokból való legózása[cite: 1].
* **Reszponzív Mobilos Kialakítás:** reszponzív rácsnézet, amely mobilon és tableten is tökéletesen adaptálódik.
* **Adatvédelem:** Minden beállítás a böngésző helyi tárhelyén (`localStorage`) tárolódik, szerveroldali adatgyűjtés nincs[cite: 1].

### 🔮 Tervezett Fejlesztések (Roadmap)
1. **Adatkezelés és Backup:** JSON alapú beállítás export/import funkció, valamint opcionális GitHub Gist szinkronizáció.
2. **Intelligens Prompt Kezelés:** Dinamikus változók (kitölthető mezők) a sablonokban és a legutóbbi promptok helyi előzményei.
3. **Gyorsbillentyűk (Hotkeys):** Billentyűparancsok az eszközök közötti villámgyors váltáshoz.
4. **Vizuális Témák:** További színsémák (világos mód, cyberpunk/matrix stílus) bevezetése.

## 🇬🇧 English

Omni AI Workspace is a browser-based, client-side (local or GitHub Pages compatible) central dashboard that provides unified, quick access to top AI models, featuring a built-in **AI Agent Builder**[cite: 1]. The UI is fully **optimized for mobile devices**, ensuring a seamless experience on smartphones and tablets as well.

### 🚀 Key Features
* **Central Toolset:** Quick access to major AI models (ChatGPT, Claude, Perplexity, Midjourney, Runway, Suno AI, ElevenLabs, Cursor, etc.)[cite: 1].
* **Smart Filtering:** Filter by categories (Text, Image, Video, Audio, Code, My Agents)[cite: 1].
* **Prompt Cheat Sheet:** Instantly insertable parameters, styles, and formatting options[cite: 1].
* **AI Agent Builder:** Create, save, and template your own fixed-behavior agents[cite: 1].
* **Mobile Friendly:** Responsive layout optimized for mobile screens and touch interactions.
* **Privacy:** All settings are stored locally in your browser (`localStorage`), with no external server required[cite: 1].

### 🔮 Future Roadmap
1. **Data & Backup:** JSON export/import feature for settings and optional GitHub Gist synchronization.
2. **Advanced Prompting:** Dynamic template variables (placeholders) and local history for recent prompts.
3. **Hotkeys:** Keyboard shortcuts for instant tool switching.
4. **Visual Themes:** Additional color themes (light mode, cyberpunk/matrix style).

## 🇩🇪 Deutsch

Omni AI Workspace ist ein browserbasiertes, clientseitiges (lokales oder GitHub Pages-kompatibles) zentrales Dashboard, das einen einheitlichen Zugriff auf die wichtigsten KI-Modelle und einen integrierten **AI Agent Builder** bietet[cite: 1]. Die Benutzeroberfläche ist vollständig **für Mobilgeräte optimiert**, sodass sie auch auf Smartphones und Tablets bequem bedient werden kann.

### 🚀 Hauptfunktionen
* **Zentrales Toolkit:** Schnellzugriff auf führende KI-Modelle (ChatGPT, Claude, Perplexity, Midjourney, Runway, Suno AI, ElevenLabs, Cursor usw.)[cite: 1].
* **Intelligente Filterung:** Filtern nach Kategorien (Text, Bild, Video, Audio, Code, Meine Agenten)[cite: 1].
* **Prompt Cheat Sheet:** Sofort einfügbare Parameter, Stile und Formatierungen[cite: 1].
* **AI Agent Builder:** Erstellen, Speichern und vorlagenbasiertes Erstellen eigener Agenten[cite: 1].
* **Mobiles Design:** Responsive Rasteransicht für Smartphones und Tablets.
* **Datenschutz:** Alle Einstellungen werden lokal im Browser (`localStorage`) gespeichert, kein externer Server erforderlich[cite: 1].

### 🔮 Geplante Entwicklungen (Roadmap)
1. **Datenverwaltung & Backup:** JSON-Export/Import-Funktion für Einstellungen sowie optionale GitHub Gist-Synchronisation.
2. **Erweitertes Prompting:** Dynamische Variablen (ausfüllbare Felder) in Vorlagen und lokaler Verlauf für kürzliche Prompts.
3. **Tastenkombinationen (Hotkeys):** Shortcuts für blitzschnellen Tool-Wechsel.
4. **Visuelle Themes:** Einführung weiterer Farbschemata (Hellmodus, Cyberpunk/Matrix-Stil).
